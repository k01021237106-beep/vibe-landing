> **새 세션 인수인계용.** 이 문서만 읽으면 인터뷰를 다시 하지 않아도 된다.
> 실행 계획은 `docs/plans/PLAN_첫배포.md` 참조.
> 작성 근거: `homepage-builder-kr` 스킬 Phase 1 인터뷰 6라운드 + Phase 2 아키텍처 확정 (2026-09-03, 사용자 승인 완료)

---

## 1. 무엇을 만드는가

코딩을 전혀 모르는 초보자에게 **바이브코딩 온라인 강의를 파는 사이트**.
소개 사이트가 아니라 결제까지 완결되는 커머스다.

**목적 (사용자 원문)**
> "코딩을 전혀 모르는 초보자도 AI와 함께 실제 서비스를 만들고 배포할 수 있도록 돕는 바이브코딩 온라인 강의를 판매하는 것"

---

## 2. 타겟과 전략

| 항목 | 내용 |
|---|---|
| **핵심 타겟** | "개발자는 아니지만 AI로 내 서비스 하나를 직접 만들어보고 싶은 사람" |
| **연령** | 제한 없음 — **중장년·시니어 초보자 포함** |
| **가장 큰 페인** | **시작 자체가 막힘** — 설치·환경설정·영어 화면·오류에서 혼자 해결 못 하고 포기 |
| **핵심 가치** | "코딩을 몰라도 AI와 함께 내 아이디어를 실제 서비스로 만들고 세상에 배포할 수 있습니다" |
| **목표 행동** | **무료 1강 신청** → 경험 → 신뢰 → 결제 (즉시 결제 아님) |

**이 답변들이 만든 설계 제약:**
- 페인이 "영어 화면에서 막힘"이므로 **사이트 자체가 영어를 쓰면 모순**이다. 영어 용어 최소화 (디플로이→배포, 리포지토리→저장소)
- 시니어 포함이므로 접근성 상향: 본문 18px+, 터치영역 48px+, WCAG AA 상회, 라이트 전용
- 목표 행동이 무료 1강이므로 **랜딩에서 결제 CTA보다 무료 1강 CTA가 위에** 온다
- 3번째 섹션이 "페인 해소"인 이유: 기능 자랑보다 "당신은 안 막힌다"는 확신이 먼저다

## 3. 브랜드

```
이름      첫배포
강의명    첫배포 바이브코딩 입문
로고      워드마크 + 라이브 점(pulsing dot) — 배포 성공 표시등에서 차용
          "당신의 서비스가 지금 살아 있다". 파비콘은 점 하나로 축소
```

### 컬러 (CSS 변수로만 관리, 하드코딩 금지)
```css
--bg:     #FBF7F0;  /* 따뜻한 크림 */
--fg:     #14110F;  /* 잉크 블랙 */
--accent: #FF5A1F;  /* 코랄 오렌지 — CTA 전용 */
```
히어로·결제 섹션만 잉크 배경으로 반전.
**딥블랙+네온그린(개발자툴 클리셰)을 일부러 피했다** — 코딩 못 하는 사람이 위축되지 않도록.

### 폰트 (3개 상한)
| 용도 | 폰트 |
|---|---|
| 헤드라인 | Paperlogy Black |
| 본문 | Pretendard 400/500 |
| 코드 | JetBrains Mono |

### 미학 방향
**에디토리얼 + 대담한 타이포**, 라이트 모드 전용. 어정쩡한 중간 금지.
피할 것: 인프런식 카드 그리드 나열형, 개발자 컨퍼런스식 딥블랙+네온, 보라 그라데이션, 이모지 아이콘.

## 4. 상품

```
강의명   첫배포 바이브코딩 입문
정가     198,000원
할인가   99,000원 (오픈 할인)
```
⚠️ **임시 가격이다.** 실제 판매 전 조정 예정 → `lib/config.ts` 한 곳에만 정의하고 모든 화면이 거기서 읽는다.
결제 시 **서버가 DB 값으로 금액을 재검증**한다. 클라이언트가 보낸 금액을 믿지 않는다.

## 5. 기능 범위

**필수** — 카카오 로그인 / 무료 1강 신청+시청 / 토스 단건결제 / 내 강의실 / 관리자 / 법적 페이지 4종
**포함** — 수강 후기(샘플 표시) / FAQ / 카카오톡 채널 상담
**2차로 미룸** — 쿠폰·할인코드, 진도율, 수료증, 블로그

## 6. 기술 스택 (확정)

```
프레임워크   Next.js 15 App Router + TypeScript
스타일       Tailwind CSS + shadcn/ui
DB/인증      Supabase (Postgres + RLS), 카카오 로그인 + 이메일 폴백
             ※ 계정은 있으나 이 프로젝트용 신규 프로젝트 생성 필요

배포         Vercel + GitHub 자동배포
도메인       없음 → vercel.app 기본 주소로 시작
언어         한국어 전용 (i18n 없음)
```

## 7. 페이지 맵

| 경로 | 내용 |
|---|---|
| `/` | 랜딩 (11섹션) |
| `/courses` | 강의 목록 |
| `/courses/[slug]` | 강의 상세 |
| `/free` | 무료 1강 신청 |
| `/free/watch` | 무료 1강 시청 |
| `/checkout/[slug]` | 결제 |
| `/checkout/success` `/fail` | 결제 승인 처리 |
| `/my` | 내 강의실 |
| `/my/[courseSlug]/[lessonId]` | 강의 시청 |
| `/admin` | 주문·수강생·리드·환불 |
| `/legal/terms` `/privacy` `/refund` | 법적 페이지 |

**랜딩 섹션 순서**
```
Hero(무료 1강 CTA) → 이런 분을 위한 강의 → 페인 해소 → 만들게 될 결과물
→ 커리큘럼 요약 → 강사 → 샘플 후기 → 가격 → FAQ → 최종 CTA → Footer
```

## 8. DB 스키마 (8 테이블, 전부 RLS 기본 차단)

| 테이블 | 역할 |
|---|---|

| `orders` | 주문/결제 내역 |
| `enrollments` | 수강권 |
| `leads` | 무료 1강 신청자 |
| `reviews` | 후기 |
| `faqs` | 자주 묻는 질문 |

## 9. 콘텐츠 상태

| 항목 | 상태 | 처리 |
|---|---|---|
| 강의명·가격 | ✅ 있음 | 그대로 사용 (가격은 임시값) |
| 커리큘럼 | ❌ 없음 | 자연스러운 한국어 예시 생성 + `TODO:` 주석 |
| 강사 프로필 | ❌ 없음 | 예시 생성 + `TODO:` 주석 |
| 수강 후기 | ❌ 없음 | 예시 생성 — **`샘플 후기` 배지 + 섹션 상단 고지 필수** |
| 사업자 정보 | ❌ 미확정 | Footer에 `추후 입력` 회색 텍스트로 자리만 |

⚠️ **후기를 실제 후기처럼 보이게 두고 오픈하면 표시광고법 위반이다.** 오픈 전 실제 후기로 교체하거나 섹션을 내린다.
⚠️ **통신판매업 신고 없이 유료 판매를 시작하면 과태료 대상이다.**

## 10. 타협 불가 보안 원칙

- 결제 금액은 **서버가 DB에서 재조회해 검증**
- Supabase Service Role Key·토스 Secret Key는 **서버 전용**
- **RLS 비활성화 금지** — 개발 편의로라도
- `.env.local` 커밋 금지, 배포 전 시크릿 스캔 필수
- Vimeo ID는 클라이언트 번들에 포함되지 않아야 함

## 11. 현재 막힌 것

**GitHub 쓰기 권한 없음.** 읽기는 되는데 쓰기만 403이다.

```
mcp__github__get_me        → OK
list_branches              → OK (main)
create_branch              → 403 "Resource not accessible by integration"
git push                   → 403
```

App은 정상 설치되어 저장소도 선택되어 있으나 **권한이 읽기 전용(Contents: Read)** 이다.
→ Contents: Read and write 부여 후 **새 세션**에서 시작해야 한다. 중간 승격은 안 된다.
