### 1강 · 무엇을 만들게 되나요 (8분 · 무료) — ✅ 대본 확정

**약속**: "강의가 끝났을 때 손에 남는 것을 먼저 봅니다. **지금 못 해도 괜찮습니다.**"

**화면 · 작업** (5조각)

| 조각 | 화면 | 하는 일 |
|---|---|---|
| 1 | `firstdeploy.kr` 첫 화면 | 인사 (40초) |
| 2 | `firstdeploy.kr` 위→아래 스크롤, 창을 좁혀 휴대폰 폭 | 완성된 것 보여주기 (2분 30초) |
| 3 | **`claude.ai/code` 웹** (빈 상태) | 한국말로 부탁 → 작업 → 결과 확인 (2분) |
| 4 | `firstdeploy.kr/#curriculum` | 여덟 강 여정 (2분) |
| 5 | `firstdeploy.kr` 첫 화면 | 안심시키기 + 준비물 (1분 20초) |

**전달할 핵심 메시지**

1. **"제가 만들었습니다. 저는 개발자가 아닙니다."** — 이 강의 전체의 근거
2. **"영어 한 글자도 없습니다. 명령어도 없습니다."** — 옆 사람한테 부탁하듯이
3. 🔑 **"이거 안 읽으셔도 됩니다. 저도 안 읽습니다."**
   ← **1강에서 가장 중요한 한 줄.** 초보가 겁먹는 건 어려운 작업이 아니라
   모르는 글자가 화면을 뒤덮는 순간이다
4. **"제 확인 없이는 아무것도 안 바뀝니다"** — 망가뜨릴 걱정 없애기
5. **"한 번에 다 이해하려고 하지 마세요. 저도 여러 번 막혔습니다."**
6. 🔴 **"준비물은 두 가지입니다. 컴퓨터 한 대, 그리고 클로드 유료 구독입니다."**
   ← **반드시 말한다. 금액은 말하지 않는다** (요금은 바뀌는데 영상은 못 고친다)

**주의** — 1강은 무료 공개분이라 **한번 나가면 되돌리기 어렵다.**
조각 3에서는 **그날 화면에 실제로 나오는 대로** 말한다. 승인 버튼이 뜨면
"허락을 물어봅니다", 변경 내용만 보여 주면 "보여 줍니다".

### 2강 · 도구 설치 (15분) — ✅ 대본 확정

**약속**: "설치가 첫 관문입니다. **눌러야 할 버튼을 하나씩 짚어 드립니다.**"

**화면 · 작업** (8조각)

| 조각 | 화면 | 하는 일 |
|---|---|---|
| 1 | `claude.ai/code` → 빈 바탕화면 | 오늘 할 일 (1분 30초) |
| 2 | `claude.com/pricing` | 🔴 유료 구독 (2분) — **건너뛰는 분도 본다** |
| — | *(여기부터 조각 5까지 「처음이신 분」 구간)* | |
| 3 | `git-scm.com/downloads/win` | Git 먼저 (2분 30초) — 맥은 건너뜀 |
| 4 | `claude.com/download` | Claude 앱 설치 (3분) |
| 5 | 앱 첫 실행 | 로그인 (1분 30초) |
| — | *(여기서 다시 합류)* | |
| 6 | **Code 탭 → 새 세션 → `Local` → `Select folder` → 「연습」 폴더** | ⭐ **2분 30초** |
| 7 | 부탁 → `index.html` 생성 → **폴더에서 더블클릭 → Chrome** | 실제로 만들기 (2분) |
| 8 | — | 마무리 (1분) |

**전달할 핵심 메시지**

1. 🔴 **"이 도구는 유료 구독이 필요합니다. 무료 계정으로는 안 됩니다."**
   ← **맨 앞에서.** 설치 다 하고 말하면 배신이다
2. **"하는 일은 똑같습니다. 자리만 옮기는 겁니다."** — 1강과 잇는 다리
3. **"여기가 이 강의에서 제일 지루한 부분입니다. 대신 한 번만 하면 다시는 안 합니다."**
4. Git은 **"여러분이 앞으로 열어 볼 일이 없는 프로그램입니다"** — 부담 줄이기
5. 설치 화면은 **"아무것도 안 바꾸셔도 됩니다. 계속 다음만 누르시면 됩니다."**
6. ⭐ **"여기서 많은 분이 막히십니다. 저도 막혔습니다."**
   → 기본이 **Cloud**로 잡혀 있어 내 폴더가 안 보인다 → **`Local`을 고른다**
7. **"여러분 화면에는 글자가 조금 다를 수 있습니다."**
   ← 이 한 줄이 버전이 바뀌어도 강의를 살린다

**⭐ 조각 6이 이 강의의 전부다.** 설치는 다음만 눌러도 되지만 `Local`을 못
찾으면 거기서 끝난다. **만든 사람도 여기서 막혔다.** 마우스를 가장 천천히 움직인다.

### 3강 · AI에게 원하는 것을 말하는 법 (18분) — 🟡 초안 (2026-09-09)

**약속**: "어떻게 말해야 원하는 결과가 나오는지, **문장 몇 개면 충분합니다.**"

**화면**: **2강에서 만든 「연습」 폴더를 그대로 이어서 쓴다.** 새 폴더를 만들지 않는다.

**화면 · 작업** (7조각)

| 조각 | 하는 일 |
|---|---|
| 1 | 오늘 할 일 — **"외울 건 없습니다"** (1분 30초) |
| 2 | **일부러 실패** — "예쁘게 만들어줘" (2분 30초) |
| 3 | 세 가지 — **어디를 · 무엇을 · 어떻게** (4분) |
| 4 | ⭐ **"방금 것에서 ○○만"** (4분) |
| 5 | 안 해도 되는 것 넷 — 영어·길게·정중·용어 (2분) |
| 6 | 직접 해 보기 — **영상 멈춤** (2분 30초) |
| 7 | 마무리 (1분 30초) |

**전달할 핵심 메시지**

1. **"외울 건 없습니다"** — 프롬프트를 주문으로 오해하는 걸 먼저 막는다
2. **"이건 여러분 잘못이 아닙니다"** — 안 나오는 게 정상이다
3. **어디를 · 무엇을 · 어떻게** + **한 번에 하나씩**
4. ⭐ **"방금 것에서 ○○만"** ← **3강의 전부.** 처음부터 다시 쓰지 않는다
5. **"평소에 말하듯이, 짧게, 하나씩"** — 영어도 정중함도 용어도 필요 없다

**저장되어 있던 것** (1강·2강이 미리 약속해 둔 말 — 이 대본의 근거):

- 1강 조각3-⑤ — *"어떻게 말해야 원하는 게 나오는지 — 그게 3강입니다"*
- 1강 조각3-⑤ — *"물론 처음엔 원하는 대로 안 나옵니다"*
- 2강 조각8 — *"사실 여기서부터가 진짜 재미있습니다"*

> **조각 4가 전부다.** ①②③은 몇 번 하면 저절로 는다.
> 하지만 **"안 나왔을 때 그만두는 사람"**은 여기서 강의를 떠난다.

### 먼저 찍어야 할 것

**① 1강** — 이유가 셋이다.

- **무료 공개분**이라 손님이 가장 먼저 보고, 판매 전에 있어야 한다
- 대본이 확정됐고 **화면이 다 준비돼 있다** (`firstdeploy.kr`, `claude.ai/code`)
- 8분으로 가장 짧다 — **첫 촬영 경험용으로 가장 안전하다**

**② 2강** — 대본이 확정된 나머지 하나. 다만 두 가지 때문에 1강보다 뒤다.

- **촬영 방법이 아직 안 정해졌다** (준비 30분)
- 설치는 변수가 많아 **약 3시간 30분** 걸린다 (1강은 2시간 25분)
- **다만 조각 6~7은 지금 계정에서 바로 찍을 수 있다** — 이미 확인된 흐름이다

### 나중에 찍어도 되는 것

**③ 3강** — 🟡 초안이 나와 있다 (2026-09-09). **2강 끝 상태에서 이어서 찍는다** —
「연습」 폴더에 2강에서 만든 `index.html`이 그대로 있어야 한다.

**④ 4 → 5 → 7 → 8강 (이 순서를 지킨다)**

만드는 작업이 **앞 강의 결과 위에 쌓인다.** 순서를 바꾸면 화면이 안 맞는다.

```
2강 index.html  →  4강 첫 화면  →  5강 글·사진  →  7강 배포  →  8강 내 주소
```

**⑤ 6강 — 맨 마지막**

4·5·7강을 찍는 동안 **실제로 막힌 장면을 모아 두고** 그걸로 만든다.

## 대본을 읽지 않고 찍는 법

**문장을 외우지 않는다. 강마다 이것 두 개만 손에 쥔다.**

1. **그 강의 약속 한 줄** (DB `summary`) — 이걸 못 지키면 다시 찍는다
2. **빠뜨리면 안 되는 말** (아래 표) — 이건 말이 조금 달라져도 뜻은 꼭 나가야 한다

나머지는 **화면을 보면서 자연스럽게** 말하면 된다.

> **어눌해도 괜찮다. 오히려 낫다.**
