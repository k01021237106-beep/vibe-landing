# 촬영 체크리스트 — 처음 찍는 사람을 위한

**대상**: 영상 촬영을 한 번도 안 해 본 사람
**쓰는 법**: 촬영하는 날 이 문서를 **인쇄하거나 휴대폰에 띄워** 놓고 위에서부터 따라간다.
**컴퓨터 화면에는 띄우지 않는다** — 녹화에 같이 찍힌다.

> 이 강의는 **화면 녹화 + 목소리**다. 얼굴은 나오지 않는다.
> 카메라도, 조명도, 삼각대도 필요 없다.

---

## 한 장 요약 — 촬영하는 날 순서

```
1. 조용한 시간 정하기          → 30분 전
2. 알림 끄기 · 화면 정리        → 10분
3. 🔴 10초 시험 녹화 · 소리 확인 → 3분   ← 절대 건너뛰지 않는다
4. 조각 1 찍기 (40초)          → 5분
5. 바로 재생해서 확인
6. 조각 2, 3, 4, 5 …
7. 파일 정리 · 백업            → 5분
```

**첫날 목표는 1강 완성이 아니다. 조각 1 하나만 제대로 찍으면 성공이다.**

---

# 1. 준비물

## 이미 있는 것

| 무엇 | 설명 |
|---|---|
| 컴퓨터 | 지금 쓰시는 그거면 된다 |
| 마이크 | 아래 순서대로 좋다 |
| 물 한 잔 | 목이 마르면 목소리가 갈라진다 |
| 종이 대본 | 인쇄하거나 휴대폰에 띄운다 |

## 마이크 — 좋은 순서

1. **유선 이어폰에 달린 마이크** ← 대부분 이게 제일 낫다. 입에 가깝다
2. USB 마이크 (있으면)
3. 무선 이어폰(에어팟 등)
4. **노트북 내장 마이크** ← 제일 나쁘다. 팬 소리와 키보드 소리가 같이 들어간다

> **새로 사지 않아도 된다.** 유선 이어폰이 집에 있으면 그걸로 충분하다.
> 소리가 정말 안 되겠다 싶을 때 그때 사도 늦지 않다.

## 마이크 두는 자리

- 입에서 **한 뼘** 정도
- 입 정면이 아니라 **살짝 옆으로** 비껴 둔다
  → 정면이면 「ㅍ」「ㅂ」 소리에서 "퍽" 하고 바람 소리가 터진다

---

# 2. 조용한 자리 만들기 (촬영 30분 전)

- [ ] **집에 사람이 적은 시간**을 고른다 (이른 아침이 대체로 낫다)
- [ ] 창문 닫기 — 차 소리, 새 소리가 생각보다 크게 들어간다
- [ ] **에어컨·선풍기·공기청정기 끄기** ← 귀에는 안 들려도 녹음에는 "웅——" 하고 남는다
- [ ] 휴대폰 무음 (진동도 끈다. 책상 위 진동은 아주 크게 녹음된다)
- [ ] 방문 닫기

> 소리는 나중에 못 고친다. 화면은 다시 찍으면 되지만
> **"웅——" 소리가 깔린 8분짜리는 통째로 버려야 한다.**

---

# 3. 녹화 프로그램 정하기

> 🔎 **여기는 사장님 컴퓨터에서 함께 확인할 자리다.**
> 아래는 후보이고, 실제로 되는지 보고 하나로 정한다.

## 후보 ① Windows 게임 바 — 설치 없음

- 여는 법: **`Win` + `G`**
- 장점: 설치가 필요 없다. 지금 당장 된다
- ⚠️ **확인해야 할 것**: 게임 바는 **바탕화면과 파일 탐색기를 못 찍는다**고
  알려져 있다. 사실이라면 —
  - **1강은 괜찮다** (브라우저만 찍는다)
  - **2강은 못 쓴다** (바탕화면 「연습」 폴더, 더블클릭이 핵심 장면이다)
- 🔎 **1강 찍기 전에 바탕화면을 10초 시험 녹화해서 직접 확인한다**

## 후보 ② OBS Studio — 설치 필요, 무료

- `obsproject.com`
- 장점: **화면 전체를 다 찍는다.** 바탕화면도, 폴더도, 브라우저도
  시간 제한이 없고, 저장 위치를 내가 정한다
- 단점: 처음 열면 설정 화면이 나온다. 한 번은 같이 봐야 한다
- **여덟 강 내내 이거 하나만 쓰면 되는 게 가장 큰 장점이다**

## 후보 ③ Zoom 혼자 회의

- 혼자 회의 열기 → 화면 공유 → 녹화
- 장점: **마이크가 켜졌는지 화면에 눈으로 보인다** (초보에게 이게 크다)
- 단점: 무료 계정은 제한이 있을 수 있다 🔎

## 맥을 쓰신다면

- **`Shift` + `Cmd` + `5`** → 화면 전체 + 마이크 선택
- 맥은 기본 기능으로 바탕화면까지 다 찍힌다

---

# 4. 화면 세팅 (녹화 시작 전 10분)

- [ ] **알림 끄기** — 윈도우 `집중 지원` / 맥 `방해금지 모드`
      → 촬영 중 카톡 알림이 뜨면 그 조각은 버린다
- [ ] 브라우저 탭을 **필요한 것만** 남긴다 (1강은 두 개)
- [ ] **즐겨찾기 바 숨기기** — `Ctrl` + `Shift` + `B`
      → 개인 북마크가 영상에 그대로 나간다
- [ ] 브라우저 **확대 125%** — `Ctrl` + `+`
      → 어르신 손님이 본다. 작으면 안 보인다
- [ ] 바탕화면 아이콘 정리 (2강에서 바탕화면이 나온다)
- [ ] 화면 해상도는 **1920 × 1080**이면 무난하다
- [ ] 대본은 **종이나 휴대폰**에 (화면에 띄우면 녹화된다)

---

# 5. 🔴 화면에 절대 나오면 안 되는 것

한 번 올라가면 되돌리기 어렵다. **녹화 시작 전에 눈으로 훑는다.**

- [ ] 내 **이메일 주소** (로그인된 화면, 메일함, 브라우저 프로필 아이콘)
- [ ] **API 키·비밀번호** — Supabase 화면, Vercel 환경변수 화면, `.env` 파일
- [ ] **Supabase / Vercel / 토스 대시보드** — 손님 정보와 매출이 보인다
- [ ] 개인 북마크, 알림 팝업, 카톡 창
- [ ] 다른 사람 이름·연락처가 적힌 화면

> **화면 녹화는 내가 본 걸 그대로 다 찍는다.**
> "잠깐 지나갔으니 괜찮겠지"가 안 통한다. 정지시키면 다 읽힌다.

---

# 6. 🔴 마이크 확인 — 10초 시험 녹화

**이 단계를 건너뛰면 안 된다.** 처음 찍는 사람이 가장 많이 겪는 사고가
**마이크가 안 켜진 채로 8분을 다 찍는 것**이다. 화면은 멀쩡한데 소리가 없다.

## 순서

1. 녹화 시작
2. 화면에 **마이크 표시가 켜져 있는지** 눈으로 본다 (보통 마이크 그림)
3. 평소 말하는 크기로 **10초** 말한다
   > "하나 둘 셋. 안녕하세요, 첫배포의 김경옥입니다. 하나 둘 셋."
4. 마우스를 조금 움직이고, 스크롤도 한 번 해 본다
5. 녹화 정지
6. **파일을 찾아서 재생한다** ← 여기까지 해야 확인이다

## 재생하며 확인할 것

- [ ] **내 목소리가 들리는가** (가장 중요)
- [ ] 너무 작지 않은가 / 너무 커서 지직거리지 않는가
- [ ] "웅——" 하는 배경 소리가 깔려 있지 않은가
- [ ] 화면 글씨가 **읽히는가**
- [ ] 찍으려던 부분이 다 들어왔는가 (특히 바탕화면 🔎)

> **이어폰을 끼고 들어 본다.** 스피커로 들으면 잡음이 안 들린다.

**하나라도 이상하면 여기서 고친다.** 본 촬영으로 넘어가지 않는다.

---

# 7. 녹화 시작 · 정지 — 3초 규칙

```
녹화 시작 → 【3초 가만히】 → 말하기 시작 …… 말 끝 → 【3초 가만히】 → 정지
```

**왜 3초인가.**
시작하자마자 말하면 첫 글자가 잘린다. 끝나자마자 정지를 누르면
마우스 딸깍 소리가 마지막에 들어간다.
앞뒤 3초는 편집에서 **잘라내라고 남기는 여유**다.

- [ ] 시작 누르고 **속으로 셋을 센다**
- [ ] 말 끝나면 **손 떼고 셋을 센다**
- [ ] 그다음 정지

## 말할 때

- **평소보다 조금 느리게.** 손님은 따라 하면서 듣는다
- **마우스를 천천히.** 휙 움직이면 어디를 눌렀는지 안 보인다
- **스크롤도 천천히.** 특히 1강 조각 2
- 누르기 전에 **"여기를 누르겠습니다"** 하고 한 박자 쉰다

---

# 8. 실수했을 때 — 다시 찍는 법

**실수는 반드시 한다. 문제가 아니다.** 세 가지 경우로 나뉜다.

## ① 말이 살짝 꼬였다 → **멈추지 않는다**

```
"…이걸 누르시면— (아, 잘못 말했다)
 【3초 가만히】
 이걸 누르시면 이렇게 바뀝니다."   ← 그 문장만 처음부터 다시
```

녹화는 계속 돌린다. **편집에서 앞부분만 잘라내면 된다.**
멈췄다 다시 켜는 것보다 이게 훨씬 빠르다.

> **어눌해도 괜찮다. 오히려 낫다.**
> "코딩 모르는 사람도 할 수 있다"는 강의다.
> 아나운서처럼 매끄러우면 손님이 위축된다.

## ② 조각을 크게 망쳤다 → **그 조각만 다시**

1강은 **다섯 조각**으로 나눠 찍는다. 조각 하나는 1~2분이다.
조각 3을 망쳐도 **조각 3만** 다시 찍는다. 조각 1, 2는 그대로 산다.

**8분을 한 번에 찍지 않는 이유가 이것이다.**
통으로 찍다가 7분에서 틀리면 처음부터다.

## ③ 화면이 뜻대로 안 나왔다 → **지우지 않는다**

Claude가 엉뚱하게 고치거나, 오류가 뜨거나, 한 번에 안 되는 장면.
**여기에 한마디만 붙이면 가장 값진 장면이 된다.**

> "보세요, 이렇게 안 될 때도 있습니다. 그럼 다시 부탁하면 됩니다."

손님이 똑같이 막혔을 때 **"나만 그런 게 아니구나"**가 된다.
매끄러운 영상은 오히려 손님을 겁준다.

# 9. 촬영 후 파일 저장 위치

## 폴더를 미리 만들어 둔다 (촬영 전에)

바탕화면에 **`첫배포촬영`** 폴더를 만들고 그 안에:

```
바탕화면
└── 첫배포촬영
    ├── 1강
    │   ├── 시험녹화.mp4
    │   ├── 1강_조각1.mp4
    │   ├── 1강_조각2.mp4
    │   ├── 1강_조각3.mp4
    │   ├── 1강_조각4.mp4
    │   └── 1강_조각5.mp4
    ├── 2강
    └── 완성본
        └── 1강_완성.mp4
```

## 파일 이름 규칙

- **`1강_조각3.mp4`** 처럼 붙인다
- 다시 찍으면 **`1강_조각3_다시.mp4`**, 또 찍으면 **`1강_조각3_다시2.mp4`**
- **덮어쓰지 않는다.** 나중에 보니 첫 번째가 나은 경우가 흔하다

## 녹화 프로그램이 어디에 저장하는지 모르겠다면

> 🔎 프로그램마다 다르다. **10초 시험 녹화 때 파일을 직접 찾아본다.**
> 못 찾으면 본 촬영도 못 찾는다. 찾은 위치를 여기 적어 둔다:
>
> **내 녹화 저장 위치**: `________________________`
>
> (윈도우 기본은 대개 `내 PC > 비디오 > 캡처`쪽이지만 🔎 확인한다)

찍은 파일은 **그날 바로 `첫배포촬영` 폴더로 옮긴다.**

# 10. 그날 촬영이 끝나면

- [ ] 파일을 **한 번씩 재생**해 본다 (소리 나오는지만)
- [ ] `첫배포촬영` 폴더를 **USB나 클라우드에 한 벌 더** 복사한다
      → 컴퓨터가 고장 나면 다시 찍어야 한다
- [ ] 오늘 몇 번 조각까지 찍었는지 종이에 적어 둔다

> ⚠️ **영상 파일은 저장소(GitHub)에 넣지 않는다.**
> 저장소에는 **대본만** 들어간다. 영상은 나중에 Vimeo에 올린다.

# 11. 처음 찍는 사람이 가장 많이 하는 실수

| 실수 | 막는 법 |
|---|---|
| **마이크가 꺼져 있었다** | 10초 시험 녹화 (6번) |
| 배경에 "웅——" 소리 | 에어컨·공기청정기 끄기 (2번) |
| 카톡 알림이 떴다 | 집중 지원 켜기 (4번) |
| 개인 북마크가 다 나왔다 | `Ctrl+Shift+B` (4번) |
| 8분 통으로 찍다 7분에 틀림 | 조각으로 나눠 찍기 (8번-②) |
| 첫 글자가 잘렸다 | 3초 규칙 (7번) |
| 파일을 못 찾겠다 | 시험 녹화 때 위치 확인 (9번) |
| 글씨가 작아 안 보인다 | 브라우저 125% (4번) |
| 너무 잘하려다 열 번 다시 찍음 | **어눌해도 괜찮다** (8번-①) |

# 12. 예상 시간 (1강 기준)

| 단계 | 시간 |
|---|---|
| 이 체크리스트 보며 세팅 | 30분 (**첫날만**. 다음부터는 5분) |
| 대본 소리 내어 읽어 보기 | 20분 |
| 다섯 조각 촬영 (다시 찍기 포함) | 1시간 |
| 앞뒤 자르고 이어붙이기 | 30분 |
| **합계** | **약 2시간 20분** |

**하루에 다 안 해도 된다.** 조각은 며칠에 나눠 찍어도 이어 붙는다.
다만 **같은 마이크, 같은 자리**에서 찍는다. 소리가 달라지면 티가 난다.
