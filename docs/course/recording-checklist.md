# 촬영 체크리스트 — 처음 찍는 사람을 위한

**대상**: 영상 촬영을 한 번도 안 해 본 사람
**쓰는 법**: 촬영하는 날 이 문서를 **인쇄하거나 휴대폰에 띄워** 놓고 위에서부터 따라간다.
**컴퓨터 화면에는 띄우지 않는다** — 녹화에 같이 찍힌다.

> 이 강의는 **화면 녹화 + 목소리**다. 얼굴은 나오지 않는다.
> 카메라도, 조명도, 삼각대도 필요 없다.

---

## 한 장 요약 — 촬영하는 날 순서

```
1. 조용한 시간 정하기            → 30분 전
2. 알림 끄기 · 화면 정리          → 10분
3. 🔴 25초 시험 녹화 · 재생 확인  → 5분   ← 절대 건너뛰지 않는다 (6번)
4. 조각 1 찍기                   → 5분
5. 바로 재생해서 확인
6. 조각 2, 3, 4, 5 …
7. 파일 정리 · 백업              → 5분
```

**첫날 목표는 1강 완성이 아니다. 조각 1 하나만 제대로 찍으면 성공이다.**

# 1. 준비물

## 이미 있는 것

| 무엇 | 설명 |
|---|---|
| 컴퓨터 | 지금 쓰시는 그거면 된다 |
| 마이크 | 아래 순서대로 좋다 |
| 물 한 잔 | 목이 마르면 목소리가 갈라진다 |
| 종이 대본 | 인쇄하거나 휴대폰에 띄운다 |

## 마이크 — 사장님은 **USB 마이크 K66**을 쓴다 (2026-09-08~)

처음엔 노트북 내장 마이크로 찍었는데 **목소리가 작게 들어갔다.**
그래서 USB 마이크로 바꿨다.

> ⚠️ **마이크를 바꾸면 소리 설정을 처음부터 다시 확인한다.**
> 바꾼 직후 녹화가 통째로 무음이 되는 일을 실제로 겪었다 (6번 아래 기록).

**손님에게 안내할 때의 순서** (강의에서 쓸 내용):

1. **유선 이어폰에 달린 마이크** ← 집에 있으면 이걸로 충분하다. 입에 가깝다
2. USB 마이크
3. 무선 이어폰(에어팟 등)
4. **노트북 내장 마이크** ← 팬 소리와 키보드 소리가 같이 들어간다

**내장 마이크로 찍는다면** — 거리보다 이게 먼저다:

- **말하는 동안 노트북을 건드리지 않는다** ← 가장 크다.
  키보드·팜레스트 소리가 본체를 타고 그대로 들어간다. 마우스를 따로 쓴다
- **화면 쪽을 보고** 말한다 (30~50cm). 고개를 숙이면 입이 마이크 반대쪽을 향한다
- 마이크 구멍(대개 카메라 옆이나 옆면)을 팔로 가리지 않는다
- **딱딱한 책상 위**에 둔다. 이불·무릎 위는 먹먹해진다
- 촬영 전 **다른 프로그램을 닫는다** — 마이크가 팬 바로 옆에 있다

## 마이크 두는 자리

- 입에서 **한 뼘** 정도
- 입 정면이 아니라 **살짝 옆으로** 비껴 둔다
  → 정면이면 「ㅍ」「ㅂ」 소리에서 "퍽" 하고 바람 소리가 터진다

# 2. 조용한 자리 만들기 (촬영 30분 전)

- [ ] **집에 사람이 적은 시간**을 고른다 (이른 아침이 대체로 낫다)
- [ ] 창문 닫기 — 차 소리, 새 소리가 생각보다 크게 들어간다
- [ ] **에어컨·선풍기·공기청정기 끄기** ← 귀에는 안 들려도 녹음에는 "웅——" 하고 남는다
- [ ] 휴대폰 무음 (진동도 끈다. 책상 위 진동은 아주 크게 녹음된다)
- [ ] 방문 닫기

> 소리는 나중에 못 고친다. 화면은 다시 찍으면 되지만
> **"웅——" 소리가 깔린 8분짜리는 통째로 버려야 한다.**

# 3. 녹화 프로그램 — **OBS Studio로 정했다**

> ✅ **결정 (2026-09-08)** — 설치와 시험 녹화까지 끝났다.
> 화면도 목소리도 정상으로 들어가는 것을 확인했다.
> **여덟 강 내내 이거 하나만 쓴다.**

- `obsproject.com` · 무료 · 시간 제한 없음
- **화면 전체를 다 찍는다.** 바탕화면도, 폴더도, 브라우저도
- 저장 위치를 내가 정한다

## 왜 Windows 게임 바를 안 쓰는가

`Win` + `G`를 눌렀는데 **이 컴퓨터에서는 아무것도 뜨지 않았다** (2026-09-08).

고쳐서 열더라도 **2강 문제가 그대로 남는다.** 게임 바는 바탕화면과 파일
탐색기를 못 찍는다고 알려져 있는데, **2강의 핵심 장면이 바탕화면 「연습」 폴더와
더블클릭**이다. 어차피 OBS를 깔아야 한다면 지금 깔고 하나만 쓰는 편이 낫다.

> 강의에서 손님에게 안내할 때도 같은 이유로 **OBS를 권한다.**
> 다만 손님 컴퓨터에서 게임 바가 잘 될 수도 있다. 강요하지 않는다.

## 맥을 쓰는 손님에게

- **`Shift` + `Cmd` + `5`** → 화면 전체 + 마이크 선택
- 맥은 기본 기능으로 바탕화면까지 다 찍힌다. OBS를 안 깔아도 된다

# 4. 화면 세팅 (녹화 시작 전 10분)

- [ ] **알림 끄기** — 윈도우 `집중 지원` / 맥 `방해금지 모드`
      → 촬영 중 카톡 알림이 뜨면 그 조각은 버린다
- [ ] 브라우저 탭을 **필요한 것만** 남긴다 (1강은 두 개)
- [ ] **즐겨찾기 바 숨기기** — `Ctrl` + `Shift` + `B`
      → 개인 북마크가 영상에 그대로 나간다
- [ ] 브라우저 **확대 125%** — `Ctrl` + `+`
      → 어르신 손님이 본다. 작으면 안 보인다
- [ ] 바탕화면 아이콘 정리 (2강에서 바탕화면이 나온다)
- [ ] 화면 해상도는 **1920 × 1080**이면 무난하다
- [ ] 대본은 **종이나 휴대폰**에 (화면에 띄우면 녹화된다)

# 5. 🔴 화면에 절대 나오면 안 되는 것

한 번 올라가면 되돌리기 어렵다. **녹화 시작 전에 눈으로 훑는다.**

- [ ] 내 **이메일 주소** (로그인된 화면, 메일함, 브라우저 프로필 아이콘)
- [ ] **API 키·비밀번호** — Supabase 화면, Vercel 환경변수 화면, `.env` 파일
- [ ] **Supabase / Vercel / 토스 대시보드** — 손님 정보와 매출이 보인다
- [ ] 개인 북마크, 알림 팝업, 카톡 창
- [ ] 다른 사람 이름·연락처가 적힌 화면

> **화면 녹화는 내가 본 걸 그대로 다 찍는다.**
> "잠깐 지나갔으니 괜찮겠지"가 안 통한다. 정지시키면 다 읽힌다.

# 6. 🔴 시험 녹화 — **모든 강의 공통 절차**

## 규칙

> **어느 강을 찍든, 본촬영 전에 20~30초를 먼저 찍고 재생해서 확인한다.**
> **예외 없다.** 2강도, 8강도, 다시 찍는 날도 한다.

5분이면 끝난다. 이걸 건너뛰어서 잃는 것은 **그날 찍은 전부**다.

## 왜 매번 하는가

한 번 맞춰 놨다고 다음에도 맞는 게 아니다. 그 사이에 바뀌는 것들 —

- 이어폰을 다른 데 꽂았다 → 마이크가 **노트북 내장**으로 바뀌어 있다
- 윈도우가 업데이트되며 **소리 장치가 초기화**됐다
- OBS를 껐다 켜면서 **설정이 달라졌다**
- 오늘은 에어컨을 켜 놨다
- 찍을 화면이 달라졌다 (2강은 바탕화면이 나온다)

**화면은 다시 찍으면 되지만, 소리가 없는 영상은 통째로 버린다.**

---

## 순서 (5분)

1. 찍을 화면을 **실제 본촬영과 똑같이** 띄운다
2. OBS 녹화 시작 → **속으로 셋 세기**
3. 아래 대사를 **평소 말하는 크기로** 읽는다 (25초)
4. 읽으면서 **마우스를 천천히 움직이고 한 번 스크롤**한다
5. 말 끝나고 → **손 떼고 셋 세기** → 정지
6. **파일을 찾아서 재생한다** ← 여기까지 해야 확인이다

---

## 읽을 대사 (25초 안팎)

**1강 조각 1·2의 진짜 도입부다.** 시험이면서 예행연습이 된다.
잘 나오면 그대로 쓸 수도 있다.

```
안녕하세요. 첫배포의 김경옥입니다.

지금 보시는 이 사이트요.

제가 만들었습니다.

저는 개발자가 아닙니다. 코딩을 배운 적도 없습니다.

이걸 AI에게 말로 부탁해서 만들었습니다.

지금 하나도 모르셔도 괜찮습니다. 저도 그랬습니다.
```

**줄이 바뀐 자리에서 한 박자 쉰다.** 붙여 읽으면 빨라진다.

> 2강 이후에는 **그날 찍을 강의 첫 대사**를 대신 읽어도 된다.
> 길이만 20~30초면 된다. 중요한 건 대사 내용이 아니라 **재생해서 확인하는 것**이다.

## 강마다 띄워 둘 화면

| 강 | 시험 녹화 때 띄울 화면 |
|---|---|
| 1강 | `firstdeploy.kr` 첫 화면 |
| 2강 | **바탕화면 + 「연습」 폴더** ← 여기가 안 찍히면 2강을 못 찍는다 |
| 3강~ | 그날 본촬영에서 쓸 화면 그대로 |

---

## 재생하며 확인할 것

**이어폰을 끼고 듣는다.** 스피커로 들으면 잡음이 안 들린다.

- [ ] **내 목소리가 들리는가** ← 가장 중요
- [ ] 너무 작지 않은가 / 너무 커서 지직거리지 않는가
- [ ] **말이 빠르지 않은가** ← 처음 찍으면 대부분 빠르다
- [ ] "웅——" 하는 배경 소리가 깔려 있지 않은가
- [ ] 화면 글씨가 **읽히는가** (안 읽히면 `Ctrl` + `+`)
- [ ] 스크롤할 때 눈이 따라가는가 (빠르면 더 천천히)
- [ ] **찍으려던 화면이 다 들어왔는가** (특히 2강 바탕화면)

**하나라도 이상하면 여기서 고친다.** 본 촬영으로 넘어가지 않는다.

## 파일

`시험녹화.mp4`로 그 강 폴더에 **남겨 둔다. 지우지 않는다.**
본 촬영이 이상할 때 "그때는 됐는데"를 비교할 기준이 된다.

## ⚠️ 겪은 일 — 믹서 막대가 움직여도 녹화는 무음일 수 있다 (2026-09-08)

**OBS 믹서에서 막대가 말할 때 움직이는데, 녹화된 MP4는 완전 무음이었다.**

막대는 **OBS가 소리를 받고 있다**는 표시일 뿐이다.
**받은 소리를 녹화로 보내는지는 별개다.** 이 둘을 같은 것으로 보면 안 된다.

> **그래서 "재생해서 확인"까지가 시험 녹화다.**
> 막대만 보고 넘어가면 이 사고를 못 잡는다. 이게 6번을 매번 하는 이유다.

무음이면 이 순서로 본다:

1. **고급 오디오 속성 → 「오디오 모니터링」**
   ← 「모니터링만 (출력 음소거)」이면 **귀로만 가고 녹화에는 안 들어간다.**
   「모니터링 끄기」로 바꾼다
2. 볼륨 슬라이더가 바닥인지
3. 다른 플레이어로 같은 파일 재생 (트랙 여러 개면 첫 트랙만 트는 플레이어가 있다)
4. 믹서에 오디오 소스가 하나 더 있는지 — 실제 녹화되는 게 다른 소스일 수 있다
5. 장면에 **오디오 입력 캡처**를 새로 추가해 기본값으로 다시 만든다
   (원인을 못 찾을 때 가장 확실하다)

> ✅ **해결됐다 (2026-09-09).** 마이크 입력·녹음·**재생**까지 정상 확인.
> 위 순서는 다음에 또 생길 때를 위해 남겨 둔다 —
> 마이크를 바꾸거나 윈도우가 업데이트되면 다시 만날 수 있다.

**마이크를 바꾸면 소리 설정을 다시 확인한다.** 이 문제는 내장 마이크에서
USB 마이크(K66)로 바꾼 직후에 생겼다. 내장 마이크 때는 작았을 뿐 들어가긴 했다.

# 7. 녹화 시작 · 정지 — 3초 규칙

```
녹화 시작 → 【3초 가만히】 → 말하기 시작 …… 말 끝 → 【3초 가만히】 → 정지
```

**왜 3초인가.**
시작하자마자 말하면 첫 글자가 잘린다. 끝나자마자 정지를 누르면
마우스 딸깍 소리가 마지막에 들어간다.
앞뒤 3초는 편집에서 **잘라내라고 남기는 여유**다.

- [ ] 시작 누르고 **속으로 셋을 센다**
- [ ] 말 끝나면 **손 떼고 셋을 센다**
- [ ] 그다음 정지

## 말할 때

- **평소보다 조금 느리게.** 손님은 따라 하면서 듣는다
- **마우스를 천천히.** 휙 움직이면 어디를 눌렀는지 안 보인다
- **스크롤도 천천히.** 특히 1강 조각 2
- 누르기 전에 **"여기를 누르겠습니다"** 하고 한 박자 쉰다

# 8. 실수했을 때 — 다시 찍는 법

**실수는 반드시 한다. 문제가 아니다.** 세 가지 경우로 나뉜다.

## ① 말이 살짝 꼬였다 → **멈추지 않는다**

```
"…이걸 누르시면— (아, 잘못 말했다)
 【3초 가만히】
 이걸 누르시면 이렇게 바뀝니다."   ← 그 문장만 처음부터 다시
```

녹화는 계속 돌린다. **편집에서 앞부분만 잘라내면 된다.**
멈췄다 다시 켜는 것보다 이게 훨씬 빠르다.

> **어눌해도 괜찮다. 오히려 낫다.**
> "코딩 모르는 사람도 할 수 있다"는 강의다.
> 아나운서처럼 매끄러우면 손님이 위축된다.

## ② 조각을 크게 망쳤다 → **그 조각만 다시**

1강은 **다섯 조각**으로 나눠 찍는다. 조각 하나는 1~2분이다.
조각 3을 망쳐도 **조각 3만** 다시 찍는다. 조각 1, 2는 그대로 산다.

**8분을 한 번에 찍지 않는 이유가 이것이다.**
통으로 찍다가 7분에서 틀리면 처음부터다.

## ③ 화면이 뜻대로 안 나왔다 → **지우지 않는다**

Claude가 엉뚱하게 고치거나, 오류가 뜨거나, 한 번에 안 되는 장면.
**여기에 한마디만 붙이면 가장 값진 장면이 된다.**

> "보세요, 이렇게 안 될 때도 있습니다. 그럼 다시 부탁하면 됩니다."

손님이 똑같이 막혔을 때 **"나만 그런 게 아니구나"**가 된다.
매끄러운 영상은 오히려 손님을 겁준다.

# 9. 촬영 후 파일 저장 위치

## 폴더를 미리 만들어 둔다 (촬영 전에)

바탕화면에 **`첫배포촬영`** 폴더를 만들고 그 안에:

```
바탕화면
└── 첫배포촬영
    ├── 1강
    │   ├── 시험녹화.mp4
    │   ├── 1강_조각1.mp4
    │   ├── 1강_조각2.mp4
    │   ├── 1강_조각3.mp4
    │   ├── 1강_조각4.mp4
    │   └── 1강_조각5.mp4
    ├── 2강
    └── 완성본
        └── 1강_완성.mp4
```

## 파일 이름 규칙

- **`1강_조각3.mp4`** 처럼 붙인다
- 다시 찍으면 **`1강_조각3_다시.mp4`**, 또 찍으면 **`1강_조각3_다시2.mp4`**
- **덮어쓰지 않는다.** 나중에 보니 첫 번째가 나은 경우가 흔하다

## 녹화 프로그램이 어디에 저장하는지 모르겠다면

> **시험 녹화(6번) 때 파일을 직접 찾아본다.**
> 못 찾으면 본 촬영도 못 찾는다. 찾은 위치를 여기 적어 둔다:
>
> **내 OBS 저장 위치**: `________________________`
>
> (OBS는 저장 위치를 설정에서 정할 수 있다. 한 번 `첫배포촬영` 폴더로
> 맞춰 두면 옮기는 일이 아예 없어진다 🔎)

찍은 파일은 **그날 바로 `첫배포촬영` 폴더로 옮긴다.**

# 10. 그날 촬영이 끝나면

- [ ] 파일을 **한 번씩 재생**해 본다 (소리 나오는지만)
- [ ] `첫배포촬영` 폴더를 **USB나 클라우드에 한 벌 더** 복사한다
      → 컴퓨터가 고장 나면 다시 찍어야 한다
- [ ] 오늘 몇 번 조각까지 찍었는지 종이에 적어 둔다

> ⚠️ **영상 파일은 저장소(GitHub)에 넣지 않는다.**
> 저장소에는 **대본만** 들어간다. 영상은 나중에 Vimeo에 올린다.

# 11. 처음 찍는 사람이 가장 많이 하는 실수

| 실수 | 막는 법 |
|---|---|
| **마이크가 꺼져 있었다** | 시험 녹화 (6번) — **매번 한다** |
| 지난번엔 됐는데 오늘 소리가 없다 | 시험 녹화 (6번). 이어폰을 다른 데 꽂으면 장치가 바뀐다 |
| 말이 너무 빨랐다 | 시험 녹화를 재생해서 확인 (6번) |
| **믹서 막대는 움직이는데 파일은 무음** | 6번 아래 기록. 막대는 "받고 있다"는 표시일 뿐이다 |
| 마이크를 바꾼 뒤 소리가 안 들어감 | 바꾸면 소리 설정을 **처음부터** 다시 확인 (1번) |
| 배경에 "웅——" 소리 | 에어컨·공기청정기 끄기 (2번) |
| 카톡 알림이 떴다 | 집중 지원 켜기 (4번) |
| 개인 북마크가 다 나왔다 | `Ctrl+Shift+B` (4번) |
| 8분 통으로 찍다 7분에 틀림 | 조각으로 나눠 찍기 (8번-②) |
| 첫 글자가 잘렸다 | 3초 규칙 (7번) |
| 파일을 못 찾겠다 | 시험 녹화 때 위치 확인 (9번) |
| 글씨가 작아 안 보인다 | 브라우저 125% (4번) |
| 너무 잘하려다 열 번 다시 찍음 | **어눌해도 괜찮다** (8번-①) |
