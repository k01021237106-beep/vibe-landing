**상태**: ✅ 확정 (2026-09-08) — 구성·대사 확정. 설치 구간의 화면 문구만 촬영 때 채운다
**길이**: 약 16분 · 유료
**DB의 약속**: "설치가 첫 관문입니다. 눌러야 할 버튼을 하나씩 짚어 드립니다."

---

## 실제로 확인한 흐름 (2026-09-08)

사장님이 직접 해 보고 끝까지 확인한 경로다. **조각 6~7은 이 실제 흐름 그대로다.**

```
Claude 데스크톱 앱 → Code 탭 → 새 세션
  → 환경에서 Local 선택          ← 여기가 진짜 관문이었다
  → Select folder → 바탕화면 「연습」 폴더
  → "간단한 인사말이 담긴 웹페이지를 하나 만들어줘"
  → index.html 생성됨
  → 바탕화면 「연습」 폴더에서 더블클릭
  → Chrome에서 "안녕하세요!" 페이지 정상 표시
```

### 진짜 관문은 설치가 아니라 **환경 선택**이었다

사장님이 막힌 곳이 정확히 여기다 — Code 탭을 열면 **GitHub 저장소 선택만** 보이고
내 컴퓨터 폴더를 고르는 곳이 안 보인다. **Cloud가 기본으로 잡혀 있기 때문**이다.

만든 사람이 막혔으면 손님은 100% 막힌다.
**조각 6이 이 강의에서 가장 중요한 장면**이고, 가장 천천히 가야 할 자리다.

---

## ⚠️ 설치할 것이 둘이다 (윈도우)

공식 문서 (code.claude.com/docs/en/desktop-quickstart):

> On Windows, **Git must be installed for local sessions to work.**
> Most Macs include Git by default.

**사장님 컴퓨터에는 Git이 이미 있어서 한 번에 됐다.** 손님은 없다.
그대로 찍으면 손님은 Local을 골라도 안 된다.

| 순서 | 무엇 | 손님이 열어 볼 일 |
|---|---|---|
| 1 | **Git** (윈도우만) | **없다.** 클로드가 뒤에서 쓰는 부품 |
| 2 | **Claude 데스크톱 앱** | 매일 연다 |

→ **Git을 먼저 깐다.** 나중에 깔면 Local이 안 되는 걸 겪고 나서 돌아와야 한다.
→ Git은 **"열어 볼 일 없는 부품"**으로 설명한다. 그러면 부담이 줄어든다.
→ 맥 쓰는 손님은 이 조각을 건너뛰게 안내한다.

내려받는 곳: **git-scm.com/downloads/win**

## 촬영 방법 — 신규 설치 화면을 어떻게 찍나

사장님 컴퓨터에는 이미 깔려 있어 **처음 설치 화면을 재현할 수 없다.**

### 1순위 — 윈도우 새 사용자 계정 (권장)

```
설정 → 계정 → 기타 사용자 → 계정 추가
→ "이 사람의 로그인 정보를 가지고 있지 않습니다"
→ "Microsoft 계정 없이 사용자 추가"
→ 이름: 촬영용   (비밀번호 없이 가능)
```

지금 계정은 아무것도 안 건드리고, 촬영 뒤 계정을 지우면 끝난다.
바탕화면이 깨끗해 촬영에도 더 좋다.

### 2순위 — 지웠다 다시 깔기

앱을 지워도 작업하던 파일은 그대로다. 로그인이 풀리는 것만 번거롭다.

### 3순위 — 설치 구간을 말로 넘기기

**품질이 떨어진다는 것을 알고 고른다.** 2강의 약속이
"눌러야 할 버튼을 하나씩 짚어 드립니다"인데 그 약속을 못 지킨다.

> **조각 6~7은 어느 방법을 골라도 지금 계정에서 그대로 찍을 수 있다.**
> 이미 확인된 흐름이기 때문이다. 3순위를 고르더라도 가장 중요한 장면은 살아 있다.

## 손님을 두 갈래로 나누지 않는다

손님의 **99%는 처음 설치한다.** 갈림길을 만들면 왕초보는
"나는 어느 쪽이지?"부터 판단해야 한다. 그 자체가 부담이다.

→ **본편은 신규 설치 하나로 간다.** 조각 1에 건너뛰기 한 줄과 자막만 둔다.
→ **구독(조각 2)은 양쪽 다 본다.** 앱은 있는데 구독이 없는 분이 있다.
→ 건너뛰는 건 **조각 3~5(설치)뿐**이고, **조각 6에서 합류**한다.

## 촬영 실무

**막히는 장면을 지우지 않는다.** 경고창이 뜨거나 한 번에 안 되는 장면이
가장 값진 장면이다. "저도 여기서 이게 떴습니다" 한마디가 손님을 안심시킨다.

**조각 6에서는 마우스를 천천히 움직인다.** 어디를 누르는지 눈으로 따라올
시간을 준다. 다른 조각보다 느려도 된다.

**기다리는 시간은 잘라낸다.** 내려받기·설치 진행바는 편집에서 자른다.
"저는 다 받았다고 치고 넘어가겠습니다" 한마디를 넣어 두면 잘린 티가 안 난다.

**화면 문구를 읽어 주되 단서를 단다.** "여러분 화면에는 글자가 조금
다를 수 있습니다" — 이 한 줄이 버전이 바뀌어도 강의를 살린다.
